# Introducing  Prevue™
Prevue™ will draw an innovative flowchart that hugs your Python 
code.  This flowchart lets you see the **control flow** of your
script.  An SVG image file is created by Prevue™ for this purpose.
This image file can be seen in a browser or document viewer.

## Quick Start
1. Download **Prevue-main.zip**.
2. Get into the folder where **Prevue-main.zip** is located.
3. Move it as follows:</br>
                  mv Prevue-main.zip ~/preview.zip
4. Unzip **prevue.zip** and create folder **prevue**:</br>
                  cd ~</br>
                  unzip prevue.zip
5. Install svgwrite:</br>
                  pip install svgwrite
## Test Prevue™
5. Generate the image file **sort_fcns.py.svg** via two commands:</br>
                  cd ~/prevue</br>
                  python3 pv.py sort_fcns.py
6. View **sort_fcns.py.svg** in your browser.

## Why Prevue™ is Cool
- Turns real Python code into visual flow diagrams.
- Works offline, with no dependencies beyond svgwrite.
- Useful for teaching, debugging, and documentation.
- Powerful benefits with an easy learning curve.
- Can also make general-purpose flowcharts.
- Can also be used as a framework for pseudo-code.
