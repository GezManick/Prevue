# Introducing  Prevue™

Prevue™ will draw an innovative flowchart that hugs your Python 
code.  This flowchart lets you see the *control flow* of your
script.  An SVG image file is created by Prevue™ for this purpose.
The image file can be seen in a browser or document viewer.

## Quick Start and Demo

1. Make a folder named **prevue** via two Terminal commands:
   
        cd ~
        mkdir prevue

2. Unzip **prevue.zip** into folder **prevue** via one Terminal command:
   
        unzip prevue.zip

3. Generate the image file **merge.py.svg** via one Terminal command:
   
        python3 pv.py merge.py

4. View **merge.py.svg** in your browser.

## Why It’s Cool

- Turns real Python code into visual flow diagrams.
- Works offline, with no dependencies beyond svgwrite.
- Useful for teaching, debugging, and documentation.
- Powerful benefits with an easy learning curve.
- Can make general-purpose flowcharts.
- Can be used as a clear framework for pseudo-code.
